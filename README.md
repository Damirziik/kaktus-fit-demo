# Kaktus Fit — unofficial demo concept

Одностраничный демонстрационный лендинг для Kaktus Fit в Каскелене. Это не официальный сайт и не коммерческий продукт, заказанный бизнесом.

## Технологии

- Vite
- HTML
- CSS
- JavaScript

## Запуск

```bash
npm install
npm run dev
```

Production-сборка:

```bash
npm run build
npm run preview
```

## Источники

Исследованные факты, ссылки, расхождения и происхождение изображений зафиксированы в [`docs/SOURCE_NOTES.md`](docs/SOURCE_NOTES.md). Контент-план находится в [`docs/CONTENT_PLAN.md`](docs/CONTENT_PLAN.md).
